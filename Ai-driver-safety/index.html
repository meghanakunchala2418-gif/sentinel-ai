🌐 External API Integration & Hardware Adapter Guide

Current Prototype Mode: All route scores, weather feeds, and bus markers are currently operating via Simulated Benchmark Datasets. No paid external API keys are required for full testing.

How Real Production Services Connect:
  • Live Weather Services: Integrate OpenWeatherMap OneCall 3.0 or Tomorrow.io API in js/api-service.js to ingest real-time precipitation and visibility radar.
  • Road Traffic & Closures: Connect TomTom Traffic Flow & Incidents API or HERE Routing API to stream real-time congestion and culvert hazard updates.
  • Real Bus GPS Telemetry: Ingest standard NMEA 0183 ($GPRMC) streams from onboard Teltonika/Concox vehicle hardware via WebSocket.
  • Client Device Geolocation: Already supported out of the box via the "Acquire Device GPS" button using the HTML5 Geolocation API with user permission.

Transparency Notice: The system will never fabricate a successful external API connection. Stale or disconnected data feeds trigger an explicit uncertainty penalty in route scoring.

⚖️ Safety Protocols & Regulatory Notice
Advisory Dispatch System Only: This software is an advisory support tool designed for fleet dispatchers, control centre coordinators, and pre-trip route planning.

• No Autonomous Control: The system does not claim to control the bus, apply automatic brakes, or steer the vehicle.

• Driver Primacy: The driver remains 100% legally and operationally responsible for the safe navigation of the vehicle. All system recommendations are subordinate to actual road signs, traffic police directives, and human visibility.

• No In-Transit Distraction: In-cabin drivers must never view, browse, or touch navigation screens while the vehicle is in motion.

• Simulated Benchmarks: The prototype uses illustrative simulation routes. It does not present unverified simulated data as real-time highway facts.
